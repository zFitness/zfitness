# 《重阳节，菊花送给你》——幼儿园小班活动配套 AI 教具材料

本仓库用于托管《重阳节，菊花送给你》小班综合活动教案的配套 AI 教具材料，供教案中的二维码扫码访问。

## 内容

| 文件 | 说明 |
| --- | --- |
| `index.html` | 教具材料展示页（含动画短片播放器、绘本三页、主题墙与教学卡片） |
| `media/chongyangjie_story.mp4` | AI 绘本动画短片《菊花送给你》，15 秒 / 16:9 / 720p |
| `media/book_p1.png` ~ `book_p3.png` | AI 绘本《菊花送给你》第 1—3 页插图 |
| `media/theme_wall.png` | 重阳节敬老主题墙主视觉 |
| `media/customs_grid.png` | 重阳节四习俗四宫格教学卡片 |
| `media/craft.png` | 皱纹纸小菊花与祝福卡手工成品 |
| `media/cover.png` | 动画短片封面 |

## 生成方式

- 插画：MiniMax **image-01** 文生图模型（角色参考 + 固定 seed，启用 AIGC 水印）
- 动画短片：MiniMax **H3** 视频模型（三张绘本插画作为分镜参考图）

## 说明

材料仅用于幼儿园教学活动设计展示，不含任何真实幼儿影像与人脸信息。
